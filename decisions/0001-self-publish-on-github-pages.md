# 0001: Self-publish the series on GitHub Pages (not Medium)

- Status: Accepted
- Date: 2026-11-26

## Context

The original plan was to publish on Medium. Concerns: paywall vs. free access for
students, poor handling of long code and copyable prompts, and depending on Medium's
changing distribution and AI-content policies.

## Decision

Publish the series as a free tutorial site built with Astro Starlight, hosted on
GitHub Pages (custom domain to follow). Medium is dropped entirely.

## Consequences

- Full control over code blocks, prompt layout, diagrams and URLs.
- Free to read; can be set as course reading.
- Readers will not find it by default: promotion is our job (Simon Martinelli,
  LinkedIn, teaching use, search).
- "Articles" become "lessons". Slugs are permanent once published.
- Book rights stay with the author; licence to be decided (see 0002).
